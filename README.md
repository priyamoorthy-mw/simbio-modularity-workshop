# SimBiology Modularity Workshop — ADC Bystander Model

A hands-on workshop for SimBiology's **modularity** feature (introduced in R2026b). Starting
from a small, validated model repository of reusable **submodels**, you assemble a modular version of
the antibody–drug conjugate (ADC) **bystander-killing** tumor model of [Wood et al. (2025)](https://doi.org/10.1371/journal.pcbi.1012839),
connecting the pieces with **equivalence sets** — and finish able to extend the framework.

## Start here

**[WorkshopGuide.md](WorkshopGuide.md)** — the step-by-step guide, using the SimBiology
Model Builder and Model Analyzer apps.

**[WorkshopGuide_CommandLine.m](WorkshopGuide_CommandLine.m)** — a live script with the
equivalent command-line steps. Each section matches a section of the guide, and you can run
it on its own from the repository root.

## Requirements

- MATLAB **R2026b** or later, with the **SimBiology** product.

## Getting the files

Clone the repository, or use MATLAB's **Home ▸ New ▸ Git Clone** and enter this repository's URL.
